Il proprietario usa un token fine-grained: solo networking-data, permesso Contents: Read and write. Per un collaboratore esterno GitHub richiede un token classic con repo, che può accedere anche agli altri suoi repository privati.

La password locale protegge la copia su questo dispositivo. Non è un account e non invita altre persone.
